# Política de imagens e créditos

A versão 0.1 usa apenas CSS para representar equipamentos. Não inclui fotografias externas nem imagens geradas por IA.

Para mídia futura:
1. Usar conteúdo de bancos de imagens com licença compatível.
2. Documentar título, autor, URL, licença e data de acesso.
3. Não presumir fair use para reutilização de qualquer imagem.
4. Respeitar atribuição, marcas e direitos de terceiros.
