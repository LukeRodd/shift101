# Segurança e privacidade

- Incidentes, IPs, logs e nomes do demo são fictícios.
- Não incluir dados internos, credenciais ou evidências de clientes reais.
- O protótipo não possui login nem dados pessoais; não usar como ambiente multiusuário em produção.
- Nenhuma rota executa comandos ou mudanças em redes, servidores e dispositivos reais.
- Segredos futuros devem ficar fora do Git e dentro do gerenciador de segredos do ambiente.
- Antes de habilitar LLM público: adicionar limites de custo, rate limiting, controle de acesso, proteção contra prompt injection e revisão de saídas.
